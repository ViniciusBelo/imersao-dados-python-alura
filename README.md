# 📊 Dashboard de Salários na Área de Dados

Projeto desenvolvido durante a Imersão de Dados da Alura, com foco em análise exploratória e visualização interativa de salários na área de dados utilizando Python.

## 🚀 Sobre o Projeto

Este dashboard interativo permite analisar salários na área de dados considerando:

* 📅 Ano

* 🎓 Senioridade

* 📄 Tipo de contrato

* 🏢 Tamanho da empresa

* 🌍 País de residência

A aplicação foi desenvolvida com Streamlit, permitindo filtros dinâmicos e visualizações interativas.

## 🧠 Problema de Negócio

O projeto busca responder perguntas como:

* Quanto ganha um Data Scientist em diferentes países?

* A senioridade impacta diretamente no salário?

* Empresas maiores pagam mais?

* O trabalho remoto influencia a remuneração?

## 📈 Funcionalidades

* Filtros Dinâmicos

* Ano

* Senioridade

* Tipo de contrato

* Tamanho da empresa

## 📊 KPIs

* Salário médio anual (USD)

* Salário máximo

* Total de registros

* Cargo mais frequente

## 📉 Visualizações

* Top 10 cargos por salário médio

* Distribuição de salários (histograma)

* Proporção de trabalho remoto

* Mapa global com salário médio de Data Scientists

## ⚙️ Como Executar o Projeto
1. Clone o repositório
```bash
git clone https://github.com/ViniciusBelo/imersao-dados-python-alura.git
```

2. Entre na pasta do projeto
```bash
cd imersao-dados-python-alura
```

3. Instale as dependências
```bash
pip install -r requirements.txt
```

4. Execute o dashboard
```bash
streamlit run app.py
```
